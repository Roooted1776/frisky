## Locked commercial rules (do not soften)

| Rule | Standing |
|------|----------|
| Language | Rider is **bilingual EN / 中文**. Both columns same meaning. If they conflict, English controls until counsel says otherwise. |
| Freight | **Own line** on the quote / PO / invoice. Never buried in unit price. |
| QC window | **5 calendar days** after buyer receives the lot at the ship-to address. Written accept or reject inside that window. |
| Second deposit | **No second deposit** (and no balance / production release) until buyer sends **written** accept or reject of the QC lot. |
| WhatsApp / WeChat voice | **Verbal WhatsApp / WeChat / phone ≠ standing.** Only signed PDF, email from the buyer address on the PO, or a written message that restates the change and is saved. |
| Spec if blanks fail | **[GUESS]** If a blank on the rider stays empty after both sides sign, **written Spec A** (this rider + band law) is what you enforce. Counsel confirm. |
| Governing law / signer | **Counsel owns** NJ vs DE vs China law, forum, and **who signs once the LLC exists**. Leave those blanks for counsel. Do not invent “NJ law” on a China factory PO without them. |

## QC checklist (5-day window)

Use these. Fail any line → written reject (photo + short reason). Pass all → written accept.

| Check | Pass |
|-------|------|
| Silicone color | Black `#232425` (or factory-agreed swatch). No wine / burgundy / navy. |
| Size | Adult adjustable ~240 mm. |
| Face art | Logo-print RedMed heart + wordmark ~30×9 mm. Not laser-only `MED ID`. |
| Chip | NXP NTAG216, 13.56 MHz, Type 2. |
| NDEF | Blank / unlocked. No factory URL. No lock. Owner can overwrite. |
| Count | Qty received = PO qty (± agreed scrap). |
| Freight invoice | Matches the **freight line** (not rolled into unit price). |

## Do not

- Soften the second-deposit gate for “we already started molds.”
- Treat a voice note or thumbs-up sticker as accept / change order.
- Pay production MOQ before sample QC accept + NFC write proof.
- Put PHI, medical claims, or “HIPAA” on factory packaging copy
  ([`FDA-CLAIMS-WALL.md`](FDA-CLAIMS-WALL.md)).
- Commit a signed rider with home address into this public repo.

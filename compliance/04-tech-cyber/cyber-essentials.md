# Cyber Essentials

## Target

- **Cyber Essentials** minimum for many public-sector deals.
- **Cyber Essentials Plus** commonly expected for NHS supplier conversations.

## Scope suggestion for RedMed today

Include: company endpoints, build machines, Apple Developer / GitHub / email
tenancy, any future cloud. The **iOS app binary** is not itself a CE “boundary”
the way a SaaS VPC is — CE is organisational.

# 7. Get into a buying route

DTAC evidence does **not** put RedMed on shelves. You still need a commercial
path into the NHS.

## Realistic routes

| Route | Fit for RedMed now | Notes |
|-------|--------------------|-------|
| Direct trust tender / local procurement | Possible for small pilots | Bring DTAC pack + CSO; expect IG + clinical safety review |
| Framework (e.g. relevant Digi / health frameworks when eligible) | Medium-term | Needs company readiness: CE+, DSPT, insurance, case study |
| NHS Innovation Service / HIN / AHSN-style support | Good early | Help shaping value case; not automatic adoption |
| Category / national deals | Later | Usually needs scale evidence and stronger assurance |

## What trusts ask beyond DTAC

- Clinical safety case they can run DCB0160 against
- DPIA they can adopt or reference
- Cyber Essentials (+)
- Contract / liability / cyber insurance
- Pilot success metrics (time-to-ID, rescuer usability — not clinical efficacy theatre)

## Positioning that matches intended purpose

Sell **emergency ID + SOS assist**, not “clinical triage app”. If a buyer wants
CDS, that is a different regulatory and sales motion — reopen RM-IP-001 first.

- [ ] Pick one pilot trust / ambulance / urgent care partner

- [ ] Agree pilot protocol that does **not** claim clinical outcomes you cannot measure
- [ ] Only then talk framework onboarding

# 2. Clinical safety — DCB0129

NHS digital health products that can affect patient care need a **Clinical
Safety Officer (CSO)** and DCB0129 artefacts. This is the hard NHS-specific lift.

**You must appoint a real CSO.** Templates below are not a substitute for a
named competent person.

| Artefact | File | Status |
|----------|------|--------|
| Outbound brief for candidates | [cso-engagement-brief.md](cso-engagement-brief.md) | **Send this** to consultancies / clinicians |
| CSO appointment record | [cso-appointment.md](cso-appointment.md) | Fill name + contract on signature |
| Clinical risk management plan | [clinical-risk-management-plan.md](clinical-risk-management-plan.md) | Draft |
| Hazard log | [hazard-log.md](hazard-log.md) | Seed hazards; CSO scores |
| Clinical safety case report | [clinical-safety-case-report.md](clinical-safety-case-report.md) | Skeleton |

DCB0160 applies to the **deploying** NHS organisation. RedMed as manufacturer /
supplier works to **DCB0129**; the trust will run DCB0160 on their side.

Do not alter app code from this folder. Safety mitigations that need product
changes go through a normal product PR after CSO approval.

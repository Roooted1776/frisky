# DSP Toolkit (DSPT) checklist

**When required:** if you process NHS organisation data, connect to NHS systems,
or sell into trusts that mandate DSPT for suppliers.

**Current RedMed:** no NHS org data processing, no Spine, no RedMed cloud EHR.
DSPT may still be **commercially required** by a buyer even for on-device apps.

## Prep checklist

- [ ] Decide organisation entity that will submit DSPT
- [ ] Create NHS Digital / DSPT account for that entity
- [ ] Complete assertions for your actual architecture (on-device = many
      “cloud hosting” controls are N/A — document why)
- [ ] Evidence folder: policies, access control, incident response, staff
      training, supplier list
- [ ] Align with Cyber Essentials evidence (step 4)
- [ ] Annual renewal calendar

## Reality check

DSPT is an organisational assurance return, not an app store badge. Empty
“N/A everywhere” without narrative fails buyer scrutiny. Write the N/As with
architecture facts.
